### 🔭 Key Projects

- **RetroLive** — Real-time Retrospective Board for Teams  
  A host shares a code and everyone joins from their own device without an account. Notes, votes, phases and a timer update instantly with Socket.IO, the server enforces the rules (exactly 3 votes per person, even under concurrent clicks), and an AI summary turns the notes into themes and action items. Built with React, TypeScript, Express, Prisma, PostgreSQL and Docker, with 97 backend, 49 frontend and 39 end-to-end tests.  
  [GitHub](https://github.com/ahmedjenhani/RetroLive) • [Live Demo](https://retrolive.vercel.app)

- **Job Tracker** — Full-Stack Job Application Tracker  
  A Kanban board for applications, analytics on the whole funnel, daily follow-up reminders by notification and email, and AI help to fill the form from a pasted job posting and to prepare interview questions. Built with Angular, Spring Boot, PostgreSQL, Flyway, JWT and Docker, with 45 backend, 21 frontend and 24 end-to-end tests.  
  [GitHub](https://github.com/ahmedjenhani/job-application-tracker) • [Live Demo](https://job-application-tracker-one-flax.vercel.app)

- **ITBS Network Security** — End-to-end MLOps Pipeline for Phishing Detection  
  Ingestion from MongoDB, validation, transformation and training, with typed artifacts and dedicated exceptions and logging between stages. A FastAPI service trains the model and predicts from an uploaded CSV, experiments are tracked with MLflow and DagsHub, and CI/CD with GitHub Actions deploys a Docker image to GCP through a self-hosted runner.  
  [GitHub](https://github.com/ahmedjenhani/ITBSNetworksecurity2)

- **StockFlow** — Pharmacy and Small-Business Management (internship project at Doctor Sina)  
  Stock and expiry tracking, barcodes, Excel import and export, a cart-based point of sale with invoices and payments, roles and permissions, and KPI dashboards. Built with Laravel, PHP, Tailwind CSS and Blade.  
  [GitHub](https://github.com/ahmedjenhani/sujet-PFE-20252026)

- **ShopEase** — Full-Stack E-commerce Website  
  Authentication, product browsing, cart and payment, plus an admin dashboard to manage inventory and follow orders. Built with MongoDB, Express.js, Angular, Node.js and TypeScript (JWT, REST APIs).
